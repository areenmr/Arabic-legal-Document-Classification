# Arabic Legal Document Classification

An NLP-based system for classifying Arabic legal documents using Saudi commercial court cases.

The project performs two main tasks:
- Verdict Prediction
- Legal Topic Classification

## Technologies
- Python
- Natural Language Processing (NLP)
- Scikit-learn
- TensorFlow / Keras
- TF-IDF
- Linear SVM
- Logistic Regression
- NLTK
- Gradio

## Dataset
The project uses the ALARB (Arabic Legal Argument Reasoning Benchmark) dataset containing Saudi commercial court cases.

## Models
Several machine learning approaches were evaluated, including:
- Logistic Regression
- Linear SVM
- Artificial Neural Network (ANN)

Linear SVM with TF-IDF bigram features achieved the strongest overall performance.
